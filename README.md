# Bank System - Enterprise Web Portal

Enterprise vehicle license plate tracking, Egyptian Arabic ASR recognition, and automated certificate extraction platform.

## Overview

This repository contains standalone, modern, responsive HTML5 + Tailwind CSS web pages for the **Bank System** enterprise platform:

- **`index.html`**: Enterprise landing page featuring the core system capabilities, Egyptian Arabic license plate OCR preview card, automated PDF certificate extraction highlights, Google Drive cloud sync overview, and banking-grade security specifications.
- **`privacy.html`**: Google Cloud OAuth 2.0 & GDPR-compliant privacy policy page explicitly disclosing Google Drive API scopes, data retention guarantees, zero third-party data sharing, user rights, and official contact channels.

## Technologies Used

- **HTML5 & Vanilla JavaScript** (Zero build dependencies, pure static deployment)
- **Tailwind CSS via CDN** (`https://cdn.tailwindcss.com`)
- **Google Fonts** (`Inter` & `JetBrains Mono`)
- **Semantic SVG Icons** (Lightweight, self-contained, no external icon fonts)

## Deployment

These pages are ready for instant deployment to any static web hosting provider:
- **GitHub Pages**: Go to **Settings > Pages > Branch: `main` / `root` > Save**.
- **Vercel / Netlify / Cloudflare Pages**: Connect this repository or drag-and-drop the root folder.
- **Nginx / Apache / S3**: Copy `index.html` and `privacy.html` directly to your web server document root.
