01 Overview & Purpose

This Privacy Policy describes how Bank System ("the Application", "we", "our", or "us") manages, accesses, collects, and protects user data and vehicle documentation. Bank System is an enterprise software solution designed for bank vehicle license plate tracking, Egyptian/Arabic license plate OCR recognition, speech-to-text logging (ASR), and automated PDF certificate synchronization for fleet logistics.

We treat user privacy with the utmost seriousness. This application operates under strict multi-tenant boundaries and complies with modern data protection regulations including the European Union General Data Protection Regulation (GDPR) and Google Cloud Platform OAuth 2.0 User Data Policies.

02 Information We Collect

Bank System collects only the minimum necessary information required to authenticate enterprise operators and manage vehicle fleet records:

User Account Data

When administrators and fleet operators log into the application (including via Google OAuth 2.0 single sign-on), we store their full name, email address, corporate tenant ID, and assigned role credentials (e.g., Administrator, Fleet Auditor, Branch Operator).

Vehicle & Document Data

Data processed in the operational line of duty, including PDF certificates of vehicle inspection, vehicle ownership titles, license plate alphanumeric sequences (Arabic script and Latin digits), audio voice recordings for speech recognition (Egyptian Arabic ASR), and audit timestamps.

03 Google Drive API Disclosure

Bank System integrates with Google Cloud APIs to furnish automated document archiving for corporate fleet departments. In accordance with the Google API Services User Data Policy, we provide this comprehensive disclosure regarding our integration:

Mandatory Google OAuth 2.0 Scope Statement
"Bank System uses Google Drive API scopes (e.g., https://www.googleapis.com/auth/drive) solely to synchronize and access vehicle documentation files uploaded or designated by authorized administrators."

Data Retention & Third-Party Non-Disclosure Guarantee

"We do not transfer, sell, or share user data or Google Drive files with third parties. Google User Data is exclusively processed for internal document indexing and certificate tracking."

All interactions with Google Drive are strictly confined to the application's secure corporate container. The application never accesses non-vehicle personal files, private Google Drive files outside the specified workspace, photos, or unapproved folders.

Google API Limited Use Requirements Compliance:

Bank System's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

04 Data Security & Storage Architecture

We implement defense-in-depth technical and operational safeguards to protect vehicle data against unauthorized access, alteration, or disclosure:

  • Encrypted Storage: All data stored in persistence layers is encrypted at rest using AES-256. All communications over the public internet and internal microservices are enforced via TLS 1.3 protocol.
  • Containerized Server Infrastructure: Microservices executing OCR routines and ASR speech transcription are isolated in hardened containers with no external public ingress, protected behind managed VPC firewall perimeters.
  • Token Revocation Mechanisms: OAuth tokens and refresh tokens are stored in encrypted vaults and feature automated expiration windows. Administrators or operators can instantaneously revoke access tokens at any time via the console.
  • Role-Based Multi-Tenancy: Strict tenant boundary keys prevent cross-branch access or unauthorized document visibility between bank departments.

05 User Rights & Data Erasure (GDPR)

In compliance with applicable privacy laws and enterprise data stewardship guidelines, all registered users and corporate stakeholders possess the following fundamental rights:

1. Token Revocation

Immediate disconnection and invalidation of active Google OAuth 2.0 authorization grants.

2. Data Erasure

Complete purging of vehicle metadata, extracted OCR certificates, and speech transcripts upon request.

3. Account Deletion

Permanent removal of operator profiles, assigned credentials, and system audit linkage within 30 days.

To exercise any of these rights, authorized users may contact our designated compliance team using the email channels provided below.
